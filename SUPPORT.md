# Support

This repository is a sample, with no support commitment or service level agreement.

- **Bugs and questions about the code:** open a GitHub issue. Search the existing issues first, and include the command you ran, its output and your Python version. Never paste keys, tokens, endpoints or customer data into an issue.
- **Security vulnerabilities:** report them privately, as [SECURITY.md](SECURITY.md) describes.
- **The services the sample calls** (Azure OpenAI, Microsoft Foundry and Microsoft Web IQ): use their documentation, and [Azure support](https://azure.microsoft.com/support/create-ticket/).
