# Security

Please don't report security vulnerabilities in public issues, discussions or pull requests.

Report them privately instead: on this repository's **Security** tab, choose **Report a vulnerability** ([Privately reporting a security vulnerability](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)). Say what you found, how to reproduce it, and what it affects.

This policy covers the code in this repository. A vulnerability in a service the sample calls (Azure OpenAI, Microsoft Foundry or Microsoft Web IQ) belongs with that service's owner, not here.

This is a sample with no support commitment, so reports are handled as time allows.
